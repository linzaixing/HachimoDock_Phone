# HachimoDock R02 · 45° 人体跟随底座

这是首版 FDM 样机，不是已验证的量产模型。保留 R02 渲染的封闭斜撑、可调夹持、单轴转盘和隐藏式 OTG 走线。Android 应用和 ESP32 固件没有修改。

## 文件与参数

| 文件 | 用法 |
|---|---|
| `model/HachimoDock-R02.step` | 装配 STEP：在 SolidWorks 中打开作为参考，或另存成 SolidWorks 文件。导入不会保留生成器参数或原生特征树。装配不含手机、电子器件和紧固件。 |
| `model/parts-step/` | 各零件的实体 STEP，适合单独修改或重新装配。 |
| `model/print-stl/` | 按毫米输出的分件 STL；不是装配 3D 打印文件。 |
| `dimensions.json`、`build.py` | 参数化源文件。改 JSON 后重建 STEP 和 STL；无需编辑 STL 网格。 |
| `verify.py` | 复核关键几何、装配干涉和导出文件。 |
| `model/configurations/` | 62、76、90 mm 三档夹距装配，同一套零件，不需要重复打印。 |
| `model/inventory.json` | 参数快照、数量、打印外廓尺寸与实体体积；尺寸单位 mm。 |
| `model/HachimoDock-R02.glb` | 实际 CAD 的彩色浏览模型，单位米、Y 轴向上，仅供预览。 |
| `model/preview/CAD-preview.png` | 实际 CAD 的装配、正视、右视、爆炸、俯视、背部视图，手机仅为参考包络。 |
| `dimensions-example.json` | 60–94 mm 夹距、20 mm 手机厚度、156×160 mm 底座的改尺寸示例。 |
| `test_model.py` | 导出与舵机安装空间回归测试。 |
| `VALIDATION.md` | 默认配置与改尺寸示例的数字几何检查结果及未验证事项。 |

默认底座外廓 **150×154 mm**，底壳高 **41 mm**，上盖厚 **8.4 mm**；转盘直径 **126 mm**；斜撑宽 **74 mm**，手机面固定 **45°**。最高打印件到桌面约 **153 mm**，不含手机。图片没有尺寸标尺，这些是本版样机的设计尺寸，并非从图片精确测得。

### SolidWorks 二次修改

交付的是实体 **STEP**，不是 STL 转实体，也不是原生 `.SLDPRT/.SLDASM`。当前环境没有 SolidWorks，**未提供、未验证原生特征树、装配配合或运动仿真**。不要把 STEP 改扩展名当成 SolidWorks 文件。

可在 SolidWorks 打开装配或分件 STEP，按软件版本与导入选项另存为零件/装配文件。导入后的实体可作为后续直接编辑或重建特征的基础，但另存不会恢复本生成器的草图尺寸和特征历史。修改整体尺寸并重建全部配套件，请使用 JSON 参数与 Python 源文件。分件 STEP 使用打印方向；保留装配位置时请打开装配 STEP。

```bash
# 在本目录运行，建议使用 Python 3.11 虚拟环境。
python -m pip install -r requirements.txt
python build.py --config dimensions.json --out model
python verify.py --config dimensions.json --out model
python -m unittest test_model.py -v
```

`render_preview.py` 可从 GLB 重建预览图，需要另有 Blender `bpy` 与 Pillow 环境；这些不是改尺寸和导出 STEP/STL 的必需依赖。预览里的手机、地面和灯光均不在 CAD 或打印件里。

`phone_width` 是装配 STEP 的演示位置，不会改变实际零件的滑动行程。`width_min`、`width_max` 是含壳宽度目标（默认 **62–90 mm**，按每侧 1 mm 软垫）；`phone_thickness_max` 是含壳厚度上限目标（默认 **18 mm**）。两条背托凸条贴约 1 mm 软垫，薄手机可加前唇软垫来减小晃动。左右夹臂独立调节，取下手机后松开两颗 M3 沉头螺钉、把夹臂滑到合适宽度，再锁紧。请勿夹按键、折叠铰链或悬空压住屏幕。

两侧塑料内壁净距为目标手机宽度加两侧软垫，默认 **64–92 mm**；贴垫后的目标手机宽度为 **62–90 mm**。左右各有 **14 mm** 工作行程，采用滑槽导向和螺钉锁紧，**不是弹簧自动夹紧，也不是左右同步联动**。前端双托脚承重，中间留 USB-C 插头位置。

### 尺寸参数

| 参数 | 默认值 / mm | 修改效果 |
|---|---|---|
| `width_min`、`width_max` | 62、90 | 改变长槽、行程与锁紧孔位置，避免最窄档滑臂相碰；允许 54–96 范围内的目标值，改后必须复核。 |
| `phone_width` | 76 | 只改变装配夹臂位置。 |
| `phone_thickness_max` | 18 | 托脚和挡唇的厚度预留。 |
| `jaw_pad`、`slide_fit` | 1、0.35 | 软垫厚度与导向间隙，软垫不在打印件内。 |
| `base_width`、`base_depth`、`base_height` | 150、154、41 | 底座外形，部分内部接口随高度联动。 |
| `wall` | 3.4 | 底壳和斜撑壁厚。 |
| `rotor_diameter`、`wedge_width` | 126、74 | 转盘直径与斜撑宽度。 |
| `plug_opening`、`cable_bore` | 15、15 | 进线口与主轴通孔。 |
| `bearing_fit`、`shaft_fit` | 0.2、0.18 | 轴承外孔直径加量与主轴直径减量。 |
| `servo_center` | 40.3 | 舵机轴到转盘轴距离，兼作皮带张力微调。 |
| `servo_body_length`、`servo_body_width` | 23、12.6 | 舵机主体预留包络，不代表所有 SG90 批次。 |
| `servo_shaft_from_end`、`servo_clearance` | 4.5、0.35 | 输出轴到主体端面的距离与让位间隙，需按实物确认。 |

不要在切片器里整体缩放来适配手机，否则轴承、螺孔和皮带会失配。角度固定为 45°，本版不是 JSON 可调角度。

```bash
# 另一个输出目录试改尺寸，不覆盖默认套件。
python build.py --config dimensions-example.json --out model-example
python verify.py --config dimensions-example.json --out model-example
```

|---|---|---|

| `02_Base_Lid` | 1 | 上盖与轴承座。 |
| `03_Rotor` | 1 | 转盘、空心主轴与止转弧槽。 |
| `04_Wedge_45deg` | 1 | 封闭斜撑、背托、夹臂导向与进线口。 |
| `05_Jaw_Left`、`06_Jaw_Right` | 各 1 | 滑动夹臂、托脚与挡唇。 |
| `07_Driven_48T`、`08_Servo_24T` | 各 1 | 48 / 24 齿试配同步带轮。 |
| `09_Shaft_Spacer` | 1 | 主轴下部间隔环，薄壁件，先试配。 |

外购件：6805 轴承 1 个、SG90 舵机 1 个与低矮原装舵盘、ESP32-C3 1 块、GT2 154 mm 长 / 6 mm 宽闭环同步带 1 条、USB-C 数据/OTG 线、独立 5 V 舵机电源、软垫和底部防滑垫。

紧固件试配起点：夹臂 M3×8 沉头螺钉 2 颗，斜撑 M3×10 沉头螺钉 4 颗，上盖 M3×12 圆柱头螺钉 4 颗，止挡 M3×6 低头螺钉 1 颗，从动轮 M2.5×6 螺钉 2 颗。舵机与舵盘小螺钉按实物配置。锁紧前检查不顶孔底、不突出摩擦面；塑料导孔未预留热熔螺母座，请勿过拧，反复拆装可另改嵌件结构。

## 打样与装配

1. 先切 `05_Jaw_Left`、`06_Jaw_Right`，用目标手机和软垫比对开口、插头及按键。壳体可先用 PETG，约 0.20 mm 层高；斜撑底面朝下，夹臂应检查悬空处是否需要支撑。不要在切片器里整体缩放螺孔。
2. `02_Base_Lid` 顶部安装 **6805（25×37×7 mm）** 轴承；按实物和打印机误差调整 `bearing_fit`、`shaft_fit`。先试配，避免强压打印件。
3. 用 4 颗 M3 沉头螺钉从转盘底面紧固斜撑；用 **M3×6 低头螺钉**装在上盖靠前的限位孔内（装好后实测头部突出量须进入止转槽但不擦槽底）。装轴承和转盘后，从下方套入 `09_Shaft_Spacer`，再装 `07_Driven_48T`；两颗 M2.5 螺钉从下方固定在主轴端部。上盖用 4 颗 M3 螺钉固定到底壳。
4. `08_Servo_24T` 用两颗小螺钉固定到低矮的 SG90 双臂舵盘上，再用原装中心螺钉锁到舵机。两轮配 **GT2 154 mm / 6 mm 闭环同步带**。打印齿形是试配齿形，不是皮带厂商的标准刀具轮廓；先用实物验证齿合、高度、张力，避免预紧过大。SG90 及舵盘不同批次可能不同，先测实物再打完整底壳。
5. ESP32-C3 用底座的通用托架与扎带固定。薄型 USB-C 数据线从两托脚之间进入斜撑，经转盘中心穿到板端；从开口端先穿较小插头。需要时调整 `cable_bore` 和 `plug_opening`。单独给 SG90 提供 5 V 并与 ESP32 共地，不从手机 OTG 给舵机供电。

建议先打印夹臂与轴承/主轴试配部件，再打印全套。PETG 可从约 0.20 mm 层高、4 圈外墙、25–35% 填充试起，受力处按切片增加局部填充。STL 已按推荐方向落在 Z=0：转盘翻面、夹臂侧放。检查转盘弧槽、夹臂挡唇、上盖台阶等悬空区域的支撑；校验通过不代表免支撑。间隔环壁厚约 0.67 mm，按喷嘴线宽检查切片结果，必要时换成实测金属间隔件。

校验采样了 -40°、-20°、0°、20°、40° 的打印件间隙，不是连续运动证明，未包含柔性皮带、实际紧固件、线缆和完整舵机齿轮箱。48/24 齿传动下，转盘角度约为舵机角度的一半，不能直接沿用原双轴结构的角度映射。**本次不修改 Android 与 ESP32 控制代码，人体跟随仍需后续实机联调。**

装电前先空转检查：转盘与上盖不擦碰；带轮不擦壳；手机最大转角时线缆没有夹压、拉紧或打结。软件限位应设在机械止挡之前。挂手机后还需确认倾倒稳定性、舵机温升和力矩。没有验证所有手机、带壳/展开折叠屏、OTG 兼容性或实机耐久。
