# HachimoDock R03：弹簧回夹样机

拉开任一侧夹臂，两根齿条经中央小齿轮等距张开；松手后，两根同规格拉簧使夹臂向内回位。手机由原结构的双托脚承重，左右软垫用于定位、防滑及降低晃动。R03 保留 R02 的底座、上盖、转盘、传动件、6805 轴承和 45° 斜撑安装角。

| `model/R03-Clamp-Preview.png` | 实际 CAD 的装盖与拆盖视图 |
| `model/configurations/` | 60 / 62 / 76 / 90 / 94 mm 名义贴垫夹距 |
| `model/print-stl/`、`model/parts-step/` | 11 个打印件的 STL 及分件 STEP；原 R02 用户只需重新打印 04、05、06、10、11 |

默认目标为含壳宽 **62–90 mm**，厚度上限目标 **18 mm**，侧垫厚度 **1 mm/侧**。空载限位 **60 mm**，全开限位 **94 mm**，每侧机械行程 **17 mm**。`REF_*` 为外购件包络，不是可打印件，也不是厂商零件模型。

## 拉簧与装配

- 样机采购 BOM：**米思米 MISUMI `AUY3-20` × 2 根/台**，标准目录轻载拉簧，无需定制。材质 SUS304-WPB，簧体外径 Ø3.0 mm，线径 Ø0.30 mm，180° 双钩。目录自由长 **20 ± 1 mm**（两钩内侧间距），最大允许挠度 **25 mm**，标称工作长度上限 **45 mm**，最大负载 **2.25 N/根**。初张力 **0.29 N**、弹簧常数 **0.08 N/mm** 均为参考值。见[厂家型号页](https://jp.misumi-ec.com/vona2/detail/110302603670/?HissuCode=AUY3-20)及[米思米中国目录](https://www.misumi.com.cn/vona2/detail/110300266030)。
- R03 的挂销中心距为 **22–39 mm**。按两端 Ø1.6 mm 销、挂钩沿中心线受拉并贴在各销外侧估算，目录口径下的工作长度为 **23.6–40.6 mm**。取自由长下偏差 19 mm，全开挠度 **21.6 mm**，较 25 mm 上限留 **3.4 mm**。按名义数据，62 / 76 / 90 mm 手机对应单根拉力约 **0.66 / 1.22 / 1.78 N**；**这不是实测夹持力**。
- CAD 保留 **Ø3.2 mm** 簧体包络，未模拟真实挂钩或摆动。首件用实物确认双钩能套入 Ø1.6 mm 销、挡肩能防脱、合盖后全行程不擦碰；再用 62 / 90 mm 试块确认回位、开合力及软垫接触。未经试配不得将目录选型视为量产放行。
- 限位件为 **Ø3 mm 光杆段**配较细的锚固段，齿轮孔为 **Ø3.26 mm**，参考肩轴光杆 **Ø3.18 mm**。斜撑孔是打样导孔；按实物修配并确认锚固可靠、齿轮转动自如。不要让螺纹直接磨滑槽或把螺钉头拧在滑件上。盖板使用与模型沉头包络吻合的紧固件，装好后头部应低于盖板表面。
- 先不装弹簧，把两个夹臂对称放在同一限位端，插入齿轮定相；装限位件，手动滑完整行程确认不掉齿、不夹死。装好两个固定端和移动端挂点、挂上拉簧，再合上盖板。确认挂点不会从打印件松脱、挂钩不碰盖板。装弹簧时佩戴护目镜，避免面向拉伸方向。
- 先用等宽试块检查：62 mm 能回夹、90 mm 留有取放余量、夹手机不压按键或折叠铰链。试配实际 USB-C 插头及线缆，在转盘全行程检查不干涉、不拉紧。确认软垫压缩、开夹手感、回位和打印层强度后，再夹持真机。

## 重建

从仓库根目录执行；预览使用 R02 棚拍工具的同一套 Blender/Pillow 依赖。

```bash
uv run --no-project --with-requirements hardware/model/r02/requirements.txt python hardware/model/r03/build.py
uv run --no-project --with-requirements hardware/model/r02/requirements.txt python -m unittest discover -s hardware/model/r03 -v
uv run --no-project --with-requirements hardware/model/r02/cmf/requirements.txt python hardware/model/r03/preview.py
```

这版是供试装和力值验证的样机 CAD，并非已验证的量产结构。STEP 保留可编辑实体；参数和建模方法位于 `build.py`，重建也需要相邻 R02 的建模源码和参数。

## 已验证与待验证

7 项几何测试通过，覆盖名义夹距、齿条啮合采样、限位、挂销防脱和代表性偏摆姿态。11 个分件 STEP/STL 均已回读核对，STL 为单个闭合实体；五档夹距、整机和拆盖 STEP 已重新打开校验。USB-C 入口与主轴通孔只做了独立净空检查，未验证带插头的线缆能否沿完整路径穿入及随转盘运动。弹簧钩形、夹持力、可靠锚固和打印公差需实物确认。
